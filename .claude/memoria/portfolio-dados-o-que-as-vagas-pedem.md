O dono **cursa Ciência de Dados na Estácio** (graduação em andamento). Em 07/09/2026 pediu
portfólio voltado ao lado de dados, "gosto, só não estou focado".

**30 vagas de dados lidas no Indeed (jobspy, 14 dias, jr/pl):** Python 18/20, SQL 13/20,
comunicação com negócio 17/20, inglês 11/20, ML 10/20, estatística 9/20, LLM/IA generativa 8/20,
Spark/BigQuery/Databricks 8/20, Excel 8/20, ETL/Airflow 7/20, Power BI 6/20, Git 2/20,
portfólio citado 2/20. Vagas júnior de IA (Quality Digital remoto, Capgemini Recife) pedem
**avaliação de LLM, prompt, MLOps/LLMOps, Databricks** e até "Claude Code/Cursor". Radix (remoto)
é a júnior clássica: pandas/scikit-learn/matplotlib + estatística descritiva + inglês intermediário.

**Plano de portfólio combinado (3 projetos, todos em Python, dado real):**
1. Análise do posto (pandas + SQL no Postgres real + notebook com conclusão de negócio).
2. Quant/backtest (série temporal, estatística, gráfico) — a paixão dele, ver
   [[python-paixao-quant-pula-de-galho]].
3. Agente FastAPI sobre o dado do posto **com eval** contra o golden master — cobre
   LLM/LLMOps das vagas de IA júnior.

**Why:** portfólio genérico (Titanic, Iris) não diferencia; dado real do posto e eval de LLM são
o que as vagas júnior de IA pedem e quase ninguém júnior tem.
**How to apply:** ao propor projeto de estudo, encaixar num dos 3. Ver [[direcao-carreira-2026]].
